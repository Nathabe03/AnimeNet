# Netflix Clone - Jujutsu Edition ⛩️

Este projeto é uma interface de streaming inspirada na Netflix, desenvolvida durante a **Imersão Front-End com IA da Alura**. O diferencial desta versão é a personalização completa com a temática do anime **Jujutsu Kaisen**, transformando a experiência de navegação em um catálogo focado no universo dos animes.

# Sobre o Projeto
O projeto foi construído do zero utilizando **HTML5, CSS3 e JavaScript**, integrando ferramentas de **IA Generativa** para acelerar a escrita de código, otimizar a estilização e resolver problemas lógicos complexos com maior produtividade.

## Personalização e Diferenciais
Embora o design siga o padrão visual moderno e minimalista da Netflix, o conteúdo foi adaptado para os fãs de cultura japonesa:
* **Temática Jujutsu Kaisen:** Perfis de usuário baseados em personagens icônicos (como Choso e Maki).
* **Foco em Animes:** Curadoria de catálogo voltada para produções japonesas.
* **Fidelidade Funcional:** O projeto mantém todas as conexões de páginas, funcionalidades de seleção e responsividade.

## Funcionalidades Técnicas
* **Persistência de Dados:** Implementação de `localStorage` para salvar o perfil ativo, permitindo que o nome e a foto do usuário escolhido apareçam dinamicamente no catálogo.
* **Responsividade Total:** Design adaptável para Mobile, Tablet e Desktop.
* **Interatividade com JS:** Manipulação do DOM para transições suaves entre a tela de perfis e a interface principal.
* **UI/UX Moderno:** Uso de ícones do Font Awesome e efeitos de hover para uma experiência imersiva.

## Tecnologias Utilizadas
* **HTML5** (Estrutura semântica)
* **CSS3** (Estilização avançada e Layouts)
* **JavaScript** (Lógica de perfis e armazenamento)
* **IA Generativa** (Suporte no desenvolvimento e debugging)
